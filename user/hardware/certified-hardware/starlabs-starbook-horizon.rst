==================
Star Labs StarBook Horizon
==================


The `Star Labs StarBook Horizon <https://starlabs.systems/pages/starbook-horizon>`__ is :doc:`officially certified </user/hardware/certified-hardware/certified-hardware>` for Qubes OS Release 4.

The `Star Labs StarBook Horizon <https://starlabs.systems/pages/starbook-horizon>`__ is a 13.4-inch laptop featuring open-source coreboot firmware, up to 32 GB of memory, Wi-Fi kill switch, integrated webcam cover, as well as extensive firmware controls for fan, power, security, boot behavior, and more.

|Photo of the Star Labs StarBook Horizon|

Qubes-certified options
-----------------------


The configuration options required for Qubes certification are detailed below.

Base Configuration
^^^^^^^^^^^^^^^^^^


- Certified: Standard (Intel Core i3-N305)

- The Plus configuration (Intel Core i5-1334U) has not yet been certified. As of this writing, we have not yet received the unit for testing, but we currently do not anticipate any significant barriers to eventual certification.



Storage
^^^^^^^


- Certified: All of the available options in these sections



Operating System
^^^^^^^^^^^^^^^^


- Certified: Qubes OS 4.3.1 or newer (within Release 4).

- Releases older than 4.3.1 are not certified.

- You may choose either to have Star Labs preinstall Qubes OS for you, or you may choose to install Qubes OS yourself. This choice does not affect certification.




Disclaimers
-----------


- As mentioned above, the "Plus" base configuration (Intel Core i5-1334U) has not yet been certified. As of this writing, we have not yet received the unit for testing, but we currently do not anticipate any significant barriers to eventual certification.
